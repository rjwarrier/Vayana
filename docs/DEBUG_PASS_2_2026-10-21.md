## F6 — P2: Do not offer an empty OCR EPUB as Text view

**Locations:**

- `format/ocr/src/main/kotlin/com/vayana/format/ocr/TextEpub.kt:36–38,116–118`
- `format/ocr/src/main/kotlin/com/vayana/format/ocr/OcrStore.kt:43,52–56`
- `feature/reader/src/main/kotlin/com/vayana/feature/reader/ReaderViewModel.kt:460,1340`

**Trigger:** A book's saved recognition results contain pages, but no recognized words. Blank or image-only content can produce this result.

**Cause:** `reflowRecognizedPages()` returns a book with zero chapters when there are no word heights. `OcrStore.buildTextEpub()` checks only whether saved pages exist, then writes that zero-chapter book. `textEpub()` considers the file available solely because it exists. The ViewModel uses that existence check to enable Text view and select the EPUB as its source.

**Impact:** The reader offers a Text view with no readable spine entries. There is no chapter it can navigate to; normal Text-view reading cannot start. This is an OCR output edge case in the existing implementation, not a demonstrated regression introduced by the recent fixes. No loss of stored scan progress was established.

**Reproduction:** `EmptyOcrProbe.java` calls the compiled production storage/reflow code, saves one valid empty recognized page, finalizes joins, builds its text EPUB and inspects the resulting ZIP:

```text
textEpub available: true
readable chapters: 0
spine has reading entries: false
page map: [null]
REPRODUCED: OCR with no words publishes an empty-spine EPUB as available Text view
```

The storage/EPUB defect was executed directly. Offering/opening that file is traced through the ViewModel source; the end-to-end device UI was not exercised.

**Suggested correction:** Require at least one readable chapter before publishing or advertising Text view, and reject already-created empty artifacts. Keep the scan available when recognition yields no usable text.

**Regression case:** Save a nonempty collection of empty recognized pages, build/finalize recognition, and assert that Text view is unavailable. Then add readable text and verify that a normal EPUB and usable page map are produced.
