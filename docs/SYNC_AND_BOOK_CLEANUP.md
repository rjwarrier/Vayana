# Source files, reading time, and Gutenberg cleanup

Replacing a source file or cleaning an EPUB changes its content hash and clears its uploaded-file reference. Run **Full Sync** on that device to upload the new file. Run Full Sync on the other device to discover the revision, then download the updated book. The old downloaded file must no longer be offered as the current revision. A pending local replacement takes priority over an older cloud copy.

Reading time travels with **reading-progress sync**, including session checkpoints and their stable IDs. A full sync is needed initially to put a new book into the cloud library, but is not needed for subsequent reading-time updates. Session IDs prevent retries from counting time twice; independent sessions from different devices add together. Pausing or closing the reader saves its final checkpoint and attempts progress sync in the application scope. If the app process is killed or the network is unavailable, the saved checkpoint travels on a later sync.

The EPUB book menu has **Clean Up**. It removes `div` or `section` elements explicitly identified as `pg-header` or `pg-footer`. It also removes missing-image placeholders from Gutenberg no-images editions: numeric codes such as `0025m` in `span` elements with matching filename-shaped `img_images_` IDs inside `div.fig` containers. Otherwise-empty figure containers are removed with them. Descriptive illustration labels, actual images, ordinary story text, and unrecognized boilerplate are preserved. Archive resources and entry names are retained. Some editions can retain an empty introductory or closing page. PDFs and other formats are not supported.

Cleanup also repairs unambiguous artifacts inside ordinary prose text nodes: repeated nonbreaking spaces between Latin letters become one normal space; soft hyphens between Latin letters (including a source line break immediately after them) are removed; zero-width spaces and embedded BOM characters between Latin letters are removed. It preserves ordinary printed hyphens and single nonbreaking spaces. Styled paragraphs, poetry, letters, tables, code, preformatted content, and explicit whitespace-preservation contexts are excluded. It does not guess OCR corrections or join words split at an ordinary hyphen.

Cleanup streams unchanged archive resources through a fixed-size buffer and reports entry progress. While cleanup is queued or running, repeated cleanup requests are disabled. The progress dialog can be hidden while work continues. Cancellation or a processing failure deletes the partial copy and leaves the source unchanged.

Cleanup writes a new EPUB before updating the book record, retains the original source file on the device, and preserves reading history and annotations. Before replacing the source, it attempts to resolve the saved CFI (including range starts) against the original chapter and capture a unique surviving passage. The cleaned copy and its passage locator are installed together. On reopening, the reader finds that passage in the cleaned chapter. Unsupported CFIs, removed artifacts, short or ambiguous passages, and unavailable positions fall back to clearing the old locator. Cached word/page estimates are cleared. Existing annotation links may shift because the document changed. There is no automatic cleanup on download.
