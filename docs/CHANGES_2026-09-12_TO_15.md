## Conventions & gotchas for the next agent

- **Annotation locators**: `epubcfi(...)` = real range; `text:...` = placed by searching `selectedText`; `quote:...` = Goodreads community quote (underline, colorKey `popular`, "N highlights" in note). Notes/Statistics treat `quote:` as not the user's own.
- **Sync never silently deletes/resurrects annotations**; books use tombstones + `deletionUpdatedAt`; purge tombstones beat everything.
- New synced fields must go into `core/backup` portable snapshot JSON (optional on read for old snapshots) and `DATABASE_CHANGELOG.md`.
- Don't add bare dp/hex colors in features (Konsist). Add tokens in `core/designsystem/.../tokens`.
- `ReaderScreen.kt` / `ReaderViewModel.kt` are very large; edit with unique anchors.
- Strings live in `core/resources/src/main/res/values/strings.xml` (English only).
