# Vayana 0.90

A physical-reading and Wear OS update since [v0.87](https://github.com/rjwarrier/Vayana/releases/tag/v0.87).

## Highlights

- **New Wear OS companion:** Cache currently-reading physical books and covers, record reading time and page updates offline, and send saved sessions to the phone after reconnecting. Includes daily goals, session reminders, ambient display, rotary page input, a reading tile and a watch-face complication.
- **Shared phone/watch timer controls:** View and control a companion timer while keeping ownership on the device that started it. Commands wait for acknowledgement; queued sessions and receipts survive restarts, and ambiguous overlaps or page conflicts stay available for review.
- **Better physical reading on the phone:** Improved timer cards and session history, page corrections, dashboard controls, and foreground notifications with pause/resume/stop actions. Hardened timer notification handling and support screens.
- **More reliable reading-time sync:** Session checkpoints carry reading time between devices without repeatedly counting earlier checkpoint time. Newer progress is preserved, backward clock changes no longer crash checkpoint recording, and unrelated ebook checkpoints no longer trigger full watch sync work.
- **Library and presentation refinements:** Updated reading-card hierarchy, dashboard presentation and motion behavior.
- **Expanded documentation:** Comprehensive user guide and README translations in Spanish, Brazilian Portuguese, French and German, plus updated Wear OS setup and troubleshooting.
- **Wear OS localization:** Moved flagged action labels and page accessibility descriptions into Android string resources.

## Downloads and installation

- **Phone/tablet:** Install `Vayana-v0.90.apk` on Android 8.0 (API 26) or newer. It uses the same release certificate as v0.87, allowing an in-place update.
- **Wear OS:** Install `Vayana-WearOS-v0.90.apk` on a Wear OS 3+ (API 30+) watch with Google Play services and a paired Android phone. Install the current phone app too; both APKs share the package identity and release certificate required for Data Layer communication. Install the watch APK on the watch, not on the phone.
- **Version:** Both APKs use version name `0.90` and version code `3`.
- **Build:** Both are signed release APKs with code minification and resource shrinking disabled. Each download has a `.sha256` checksum file.

The companion tracks physical-book reading; EPUB and PDF rendering remains on the phone/tablet. See the [Wear OS guide](../WEAR_OS.md) for offline behavior, shared controls and conflict review.

## Validation

Release signatures, packaged versions and matching phone/watch certificates are checked before publication. Android unit tests and the reader-engine suite pass. Automated checks do not verify real paired-device delivery, watch layout or reminder timing.
