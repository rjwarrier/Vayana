# Vayana 0.93

A statistics, dictionary and sync update since [v0.92](https://github.com/rjwarrier/Vayana/releases/tag/v0.92).

## Highlights

- **Statistics, redesigned:** Switch between Week, Month, Year and All time. The hero shows time read, how it compares with the same point of the previous period, sessions, days read and books finished, as a bar or line chart (your choice is remembered; tap a bar for its time). New cards show when you read (time of day, weekday, session length), your most-read books, reading time per synced device and how much you listened versus read. Cards are grouped into Reading, Books, Notes & words and Library.
- **Reading time per device:** Sessions now record which device read them, and older sessions are credited once from your GitHub sync history.
- **Listening counts:** Read-aloud listening counts as reading time, including with the screen off, and each session keeps how much of it was listened to.
- **More offline dictionaries:** Settings → Reader text → Dictionaries now installs GCIDE (Webster's 1913, downloaded from GNU and built on the phone), Olam English→Malayalam, any of FreeDict's 300+ bilingual dictionaries from an in-app catalog, or your own StarDict file. Lookups follow the book's language and add meanings in your other installed languages; you choose the order dictionaries are tried in.
- **Smarter lookups:** Possessives, contractions, archaic endings (canst, lendeth) and accents (abbé) now find their entries.
- **Learn words:** Only deliberate lookups of real dictionary words are saved, not the first word of a highlight or names the dictionaries don't know. Tap a word to see its meaning, or remove it; removals sync. A more compact layout.
- **Steadier selection:** Highlights dragged onto the next page no longer drop or stop following your finger, notably on E-Ink.
- **Reader:** The Style panel leaves the page visible so changes preview live, and the controls' back arrow exits the book (back gestures are unreliable on some E-Ink devices).
- **Sync:** Home Library books and their reading data now sync to devices without Home Library. Snapshots use a compact zipped format, so each background sync uploads about a third as much.
- **Data usage and privacy:** Settings → Help & About gains Data usage (app Wi-Fi and mobile data, per-sync traffic, kept beyond Android's own history) and Privacy & data (where your data lives, what leaves the device, and live security status).
- **Other changes:** Goodreads imports keep the screen on; measured page counts survive theme switches; 330 missing translations filled in; offline syncs no longer show up as problems in Diagnostics; Vayana is now licensed GPL-3.0-or-later.

**Upgrade every syncing device:** 0.92 and older cannot read the compact sync format, so update all devices that share a sync repository.

The database upgrades automatically (schema v37 to v41) on first launch.

## Downloads and installation

- **Phone/tablet:** Install `Vayana-v0.93.apk` on Android 8.0 (API 26) or newer. It uses the same release certificate as v0.92, allowing an in-place update.
- **Wear OS:** Install `Vayana-WearOS-v0.93.apk` on a Wear OS 3+ (API 30+) watch with Google Play services and a paired Android phone, together with the 0.93 phone app. Install the watch APK on the watch, not on the phone.
- **Version:** Both APKs use version name `0.93` and version code `5`.
- **Build:** Both are signed release APKs. Each download has a `.sha256` checksum file.

## Validation

Release signatures, packaged versions and matching phone/watch certificates are checked before publication. Unit tests for the changed modules and the reader-engine suite (182 tests) pass. Dictionary installs (GCIDE, Olam, FreeDict) and routed lookups were checked on a phone; a book in another language picking its own dictionary first has not been tried on a device.
