# Vayana 0.85 — first GitHub release

Vayana is an Android EPUB reader built around three ideas: make long-form reading feel calm, keep the reader's data portable, and treat highlights and vocabulary as material worth returning to.

This is the first build published through GitHub Releases. The attached APK is a signed, minified release build for Android 8.0 (API 26) and newer.

## What makes Vayana different

- **A dedicated E-Ink display profile.** E-Ink mode removes continuous motion, keeps reading progress as a static squiggle, disables page-turn animation, renders covers in high-contrast greyscale, supports hardware page keys, adds screen-sized paging controls to long lists, and uses shape-coded black highlights that remain distinguishable without colour. Reader refreshes can run every chosen number of pages and at clean transition points.
- **Reading becomes a learning loop.** Double-tap dictionary lookup can save words directly to a spaced-review deck. Vayana also surfaces unusual words in the current chapter, supports Anki CSV and Markdown vocabulary export, and offers a separate spaced-review flow for the reader's own highlights.
- **Read aloud stays connected to the text.** Android TTS follows the book sentence by sentence, highlights the spoken sentence or word, turns chapters automatically, and can start from a selected passage. Playback supports speed, pitch, voice and engine selection, a sleep timer, audio focus, headset/Bluetooth and lock-screen media controls. Tapping the reader pauses speech immediately.
- **Self-managed GitHub sync.** A repository chosen by the reader can synchronize library metadata, reading position, sessions, notes, highlights, shelves, vocabulary, settings and encrypted book/cover assets. Lightweight progress sync runs while reading; conflict dialogs identify the newer position with its sync time and device name. Permanent-deletion tombstones prevent deleted books from returning on another device.
- **Popular quotes and personal annotations can coexist.** Goodreads metadata can add covers, series details, genres, ratings and popular quotes. Imported community quotes appear as dotted marks with highlight counts, while the reader's own highlights, underlines, notes and review schedules remain distinct.
- **Digital and physical books share one reading life.** EPUB files can be read in-app, while physical books can still be tracked with progress, dates, ratings, notes, highlights and statistics.

## Library and organization

- Import individual EPUB files, scan a folder, or use Android's **Open with** and share sheet from a browser, mail app or file manager.
- Duplicate detection, visible per-file import progress and clear import summaries.
- Grid and list presentations with search, sorting and filters for reading state, tags and other metadata.
- A prominent **Currently Reading** card, configurable finished threshold, reading dates, time taken and book-level progress details.
- **Read Next** queue with a focused two-book limit, series-aware suggestions and a warning before breaking series order.
- Personal shelves, automatic series folders, series ordering, tags and a Recently Deleted area with restore and configurable retention.
- Add and track physical books without an EPUB file.
- Edit title, author, series, series number, tags, description, rating, reading dates and cover art.
- Fetch Goodreads metadata and preview proposed changes before applying them; import popular quotes by link, browser flow, pasted text or text file.
- Replace an EPUB source without losing the book's reading history and annotations.
- Share a book file or a visual reading card.

## Reading experience

- EPUB rendering powered by a focused Foliate-based engine with table of contents, remembered position and chapter navigation.
- Custom font family and imported fonts, font size, line height, side margins, header/footer spacing, text alignment, hyphenation and optional publisher styles.
- Light, dark, system and reader themes, including true-black and warm-light/brightness controls.
- Per-book reading preferences where a title needs different typography from the global defaults.
- Three-zone or alternate tap controls, volume-key page turns, hardware page keys, fullscreen mode, keep-awake option, page-turn animation and two-column landscape layout.
- Bionic-reading and bolder-text options.
- Footnotes open in a focused popup with an option to jump to the note.
- Welcome-back recap after time away, showing a recent highlight and due vocabulary.

## Highlights, notes and sharing

- Highlights, underlines, bookmarks and reader notes anchored to EPUB locations.
- Overlapping highlights of the same type merge cleanly instead of creating stacked duplicates.
- Hashtag-style annotation tags with filtering and suggestions.
- Global Notes view plus per-book notes, full-text search and direct navigation back to the passage.
- Import Kindle `My Clippings.txt`, match entries to books already in the library and skip duplicates.
- Export notes as Markdown.
- Create shareable quote-card images from a selection, Notes or highlight review.
- Review due highlights using **See soon**, **Got it** and **Know it well** intervals.

## Dictionary and vocabulary

- Bundled offline English dictionary lookup from the reader.
- Double-tap a word to look it up and optionally save it for review.
- Chapter vocabulary view surfaces unusual words with definitions.
- Spaced vocabulary review with due counts and known-word tracking.
- Export vocabulary for Anki as CSV or as readable Markdown.

## Search and statistics

- Fast full-text search across titles, authors, series, tags, descriptions, highlighted text, notes and chapter names.
- Prefix matching, highlighted matches, result-type filters and recent searches.
- Reading time, sessions, streaks, daily and yearly goals, books finished and date-based activity summaries.
- Book-level started/finished dates, time spent and days taken.
- Highlight and vocabulary review entry points from Statistics.

## Backup, sync and recovery

- Manual portable ZIP backup and restore for books, notes and settings.
- Automatic backups to a reader-selected folder on a daily, weekly or 30-day schedule with retention controls.
- Optional GitHub-based multi-device sync with connection testing, sync health, clear conflict handling and an encrypted setup-transfer file.
- AES-GCM encryption for cloud book and cover assets using the reader's passphrase.
- Device-aware progress conflicts show when and where the newer position was synced.
- Soft deletion that synchronizes and can be restored, plus guarded permanent deletion across devices and cloud storage.
- Diagnostics view for inspecting and sharing relevant app events.

## Appearance and navigation

- Material 3 interface with Standard and E-Ink display profiles.
- System, light and dark appearance, optional Material You colour and reduced/off motion choices.
- Floating or bottom navigation styles, adaptive layouts and navigation rail support on larger screens.
- Cohesive shared-element transitions from Currently Reading and library covers into Book Details, including predictive-back gestures.
- Onboarding for appearance, importing and sync setup.

## Installation

1. Download `Vayana-v0.85.apk` from this release.
2. Allow installation from the browser or file manager if Android asks.
3. Open the APK and install Vayana.

Android may warn that the app is from outside Google Play. The APK is signed with Vayana's release key; `Vayana-v0.85.apk.sha256` is included for integrity verification.

## Current scope

- EPUB is the supported readable ebook format in this release.
- Goodreads and GitHub sync features require internet access; core library management, reading, dictionary lookup, notes and statistics work locally.
- Vendor-specific E-Ink refresh APIs are not yet integrated; Vayana uses portable Android behavior so it works across regular Android and E-Ink devices.
